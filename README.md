# Sai Praneeth — BUDT748 Client-Side Portfolio

A responsive three-page portfolio created for the BUDT748 client-side technology assignment.

## Pages

- `index.html` — Home page with hero, data visual, metrics, and featured projects
- `about.html` — Background, experience, skills, education, and awards
- `contact.html` — Contact details and a validated static email form

## Technology

- Semantic HTML5
- Custom CSS with reusable design tokens
- Bootstrap 5.3 navbar, grid, buttons, cards, forms, and responsive utilities
- Vanilla JavaScript for the footer year and contact-form email draft

## Run locally

Open `index.html` directly, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
