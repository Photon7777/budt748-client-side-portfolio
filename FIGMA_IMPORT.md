# Figma Artboard Import

The Figma source file is:

https://www.figma.com/design/Pjb8gwbGaZ4U3TdcXIVA6c

The file already contains the portfolio variables, typography styles, elevation style, cover, usage guidance, foundations documentation, and a `Website Pages` canvas.

If the three website artboards are not yet visible on `Website Pages`, import these editable SVG exports:

- `assets/figma-exports/home-design.svg`
- `assets/figma-exports/about-design.svg`
- `assets/figma-exports/contact-design.svg`

In Figma, open `Website Pages`, press **Shift + Command + K**, select all three SVG files, and place them side by side. Each export is a 1440 px desktop design and matches the live Bootstrap site.
